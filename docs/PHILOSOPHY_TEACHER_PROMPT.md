## Research before designing the next lesson

- Research introductory philosophy pedagogy for adult novices. Verify sources directly. Start with OpenStax's Introduction to Philosophy, especially What Is Philosophy?, Philosophical Methods, and Arguments. Consult peer-reviewed work on argument mapping, examples followed by practice, retrieval, and asking explanatory questions. The IES practice guide on organizing instruction is a starting point for general learning design.
- Return a short evidence brief. For each useful source, state what was studied or what the source teaches, who it applies to, the limitation, and what you would change in this course. Distinguish evidence from your design judgment. Include verified links. Seek perspectives from more than one philosophical tradition as the course develops.
- Review the existing first lesson and 24-question bank. Map each question to a taught concept, definition, worked example, and learning objective. Flag questions whose key terms, prerequisites, or expected reasoning never appear in the teaching. Preserve useful questions that prompt curiosity and reconsideration. Propose targeted revisions to any misaligned items and keep stable question IDs where the learning target is unchanged.

## Course structure and format

Use **Class → Unit → Lesson → Section**. The starting outline has four units and two lessons per unit. Unit 1 covers questions, reasons, and argument maps. Unit 2 covers knowledge, evidence, and disagreement. Unit 3 covers ethics and shared life. Unit 4 covers reality, identity, and art. Lesson 1 is available. Treat the other titles as a plan. Check the prerequisites and explain any proposed rearrangement.

For each lesson, give a guiding question, what the learner should already know, and 3–6 measurable goals. Start the entire course with a usable definition of **philosophy**, in the first paragraph. Define each important new term where it appears. Format the term in bold and its concise definition as highlighted text. Reuse the exact term and compatible definition in the end glossary, cards, exercises, and assessment. Limit how many terms arrive together. Spell out technical terms before using shorthand.

For each section, include a familiar example, a short explanation, and a brief numbered list of 2–4 questions that can each become a separate notebook draft. Make the first question approachable and let later questions ask for application or explanation. Use ★ for an important tip. When useful, give an analogy and show exactly where it stops fitting. Use a small comparison table or labeled boxes with arrows when the visual explains a relationship. Accompany visuals with an equivalent plain-language description for read aloud and screen readers.

Give a complete worked example before a complex independent assignment. For the fictional AI school assignment, unpack **conclusion**, **premise**, **value assumption**, **fair objection**, **reply**, and **evidence that could change my mind**. Show two premises, the value that bridges them to the recommendation, a fair challenge, a reply, and a specific result that would change the recommendation. Give me one step at a time if I am stuck. Offer feedback on the reasoning without supplying my final reflection unless I ask for a model.

## Practice and handoff

Create glossary entries and flashcards with a term, concise definition, accepted alternate wording, a short example, and an optional visual. Write plausible multiple-choice distractors for common misunderstandings. For written responses, accept equivalent reasoning and explain why. Use scenarios as well as vocabulary. Give feedback that shows how to improve the answer. Keep reflection prompts distinct from graded questions.

When I ask for a lesson handoff, return the course and unit IDs, lesson ID and revision, objectives, sections, glossary and cards, notebook prompts, optional diagram descriptions, assessment bank with correct-answer IDs and explanations, and sources. Keep voice narration natural. Include the objective-to-question alignment table and mark what needs my review before publication.
