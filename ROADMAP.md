# Growing the canopy

## Visual world

Keep Lumen & Loam as the umbrella name, StarFern as the night forest, Canopy Lab as the class atlas, and the seeds/sprouts/task-garden vocabulary. The setting is a future planet, with gentle unfamiliar wildlife and a coherent cream/moss/pearl palette that becomes indigo/evergreen/lilac after moonrise.

The first public build adds liquid-glass layers, dimensional hanging SVG vines, a more tactile Mossling, Glimmermoth, motion control, and an optional constellation memory game. Next, create the complete creature art sheet and more organic textures. Add the glass-antlered Dewfawn and petal-eared Hushhare as small native inhabitants.

## Learning

Publish teacher-chat lessons with a guiding question, key terms, competing views, examples, an exercise, recap, and sources. Add passage-level highlights, notebook search/filtering, cross-course concept links, and spaced review.

## Forest discoveries

Connect secrets into optional trails: constellations, lost seeds, small puzzles, and tiny games. Essential study tools always remain visible. Rewards add growth and curiosity without penalties for absence.

## Technical work

Validate keyboard access, contrast, reduced motion, and mobile layouts with each visual release. Keep export/import compatible as the schema grows. Account sync is a later opt-in project requiring a privacy design; GitHub Pages itself is static hosting.
